A **context-aware AI work assistant** understands the work already in front of you and helps complete the next step. Instead of opening a blank chatbot and explaining the entire situation, you can ask for a reply, rewrite, summary, prompt, or action from inside the app you are already using.

Lazur is a context-aware AI work assistant for macOS. Talk naturally, and it can use the current app, thread, document, or selection to help turn an unfinished thought into finished work.

## What context-aware means

Context is the information that makes a request useful:

- The Slack thread you are replying to
- The email recipient and previous messages
- The code file and selected function in an editor
- The document section you want shortened
- The browser page or app window you are looking at

A context-aware assistant does not treat every request as an isolated sentence. It connects the request to the work around it.

## What it can do

A personal AI work assistant can help with repetitive translation tasks:

| You need to do | Context-aware result |
| --- | --- |
| Reply to a thread | A reply that matches the conversation and requested tone |
| Rewrite a paragraph | A clearer or shorter version of the selected text |
| Start a coding task | A prompt that names the file, change, and constraints |
| Capture a rough idea | A structured note, outline, or next action |

The important distinction is the output. Voice input is only the interface. The goal is a message, decision, prompt, or action you can use immediately.

## Context-aware assistant vs chatbot

ChatGPT and other general assistants are useful when you want to explore an idea in a dedicated conversation. A work assistant is useful when the context is already present in Slack, Gmail, Cursor, Notion, or another app.

Lazur is designed for the second workflow: hold a hotkey, say what you want done, and keep the result in the app where the work started. See the [Lazur use cases](/use-cases) for examples.

## Privacy still matters

Context is powerful, so permission boundaries matter. Lazur uses local speech-to-text on Mac. Screen context is used when the relevant feature runs, not as continuous background surveillance. Read the [privacy model](/privacy) before enabling screen-aware features.

## Bottom line

A context-aware AI assistant is the layer between what you mean and the finished work. It is more useful than raw transcription when the task depends on the conversation, document, or code already on screen.
