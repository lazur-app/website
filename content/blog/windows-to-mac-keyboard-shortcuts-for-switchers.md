On a Mac, the Command key (⌘) does most of the work that Ctrl did on Windows. Option (⌥) takes the place of Alt, and Control (⌃) covers a smaller set of jobs, such as right-click.

Apple's support page says the same thing. On a Windows PC keyboard, you press Alt for Option, and the Ctrl key or Windows logo key for Command. This guide covers the shortcuts you will use every day, the ones that work differently, and the habits that waste the most time in your first week.

## The key mapping: Ctrl becomes Command, Alt becomes Option

Start with the mapping, because everything else builds on it. Apple lists Command-C for copy, Command-V for paste, Command-S for save, Command-Z for undo, and Command-Q to quit an app. Each one does the job your Ctrl shortcut did. Your thumb just moves one key over.

Apple's Windows keys page adds a useful detail. Command takes over most Ctrl shortcuts. Option is the Alt key. Holding Control and clicking performs a right-click. That gives you three rules to start with:

- When a Windows shortcut uses Ctrl, try Command first.
- When it uses Alt, try Option.
- When it uses the Windows key, try Command.

These rules cover most of what you do. They fail in a few places, and those places cost the most time. The table below lists the shortcuts you will use most, with notes on where the Mac version works differently.

| Windows | Mac | What to know |
|---|---|---|
| Ctrl+C, Ctrl+V | ⌘C, ⌘V | Same job, one key over |
| Ctrl+Z, Ctrl+Y | ⌘Z, ⇧⌘Z | Redo is Shift-Command-Z, not Ctrl+Y |
| Ctrl+S | ⌘S | Save works only where the app supports it |
| Alt+Tab | ⌘Tab | Switches apps, not windows |
| Alt+F4 | ⌘W or ⌘Q | ⌘W closes a window, ⌘Q quits the whole app |
| Ctrl+Shift+Esc | ⌥⌘Esc | Opens Force Quit, not Task Manager |
| Windows+L | ⌃⌘Q | Locks the screen |
| Windows+Shift+S | ⇧⌘5 | Opens screenshot controls |
| Windows key | ⌘Space | Opens Spotlight, the Mac version of the Start menu |
| Right-click | Control-click | Opens the contextual menu |
| Home and End | ⌘ Left Arrow, ⌘ Right Arrow | Start and end of the line |
| Delete | Fn-Delete | Deletes forward. The Mac Delete key deletes backward |

The rules hold for most jobs. They break for window switching, closing windows, and deleting text. The next sections cover those one at a time.

Windows still dominates desktop web traffic, so you are part of a minority on the Mac side. StatCounter's desktop table for October 2026 puts Windows at 76.65% of worldwide desktop traffic. It lists macOS at 5.81% and OS X at 9.86%. That table counts web visits, not computers people own, so treat it as a rough signal. The takeaway for you is simpler. Your Ctrl habits are not wrong. They just point at a different key on a Mac.

## How to read Mac shortcuts in the menus

Mac menus print shortcuts as symbols. Four matter most: ⌃ Control, ⌥ Option, ⇧ Shift, and ⌘ Command. Menus list them in that order. So ⇧⌘5 means Shift, then Command, then 5. Apple's pages write the same shortcut as Shift-Command-5. This guide uses both forms.

Try it on a real menu. Open any app and look at the Edit menu in the menu bar. Copy, Paste and Undo sit there with their shortcuts printed on the right. Read ⌥⌘Esc as Option, Command, Esc. That combination is Force Quit. Once the order makes sense, you can read most shortcuts at a glance, and you can check any command you are unsure about before you guess.

## Copy, paste, undo and save on a Mac

Most of these are a one-key swap. Press Command where you used Ctrl. Command-X cuts, Command-C copies, Command-V pastes, and Command-Z undoes.

Redo is the one that changes. Microsoft's Windows 10 and 11 keyboard page lists Ctrl+Y for redo. On a Mac, press Shift-Command-Z. If you press Command-Y out of habit, nothing useful happens, so train the new combination early.

Save is Command-S. Apple says every app can have its own shortcuts, and a shortcut that works in one app may not work in another. If Command-S does nothing, open the File menu in the menu bar and look for Save. Some apps save as you type, so you may never see a Save command at all.

Here is a worked example. Say you copy a paragraph from a web page into Apple Notes. Select the text, press Command-C, click where you want it, and press Command-V. If the paste lands in the wrong spot, press Command-Z. The whole job takes three shortcuts, and none of them needs a mouse menu.

## Switching apps and windows with Command-Tab and Command-`

This is where Windows habits fail most often. On Windows, Alt+Tab switches between windows. On a Mac, Command-Tab switches between apps. Apple says it jumps to the most recently used app among the ones open.

Command-` (the grave accent, the key above Tab) switches between windows of the app you are using. If you have three browser windows open, Command-` cycles through them. Command-Tab would take you to a different app instead.

Consider a real afternoon. You have three Chrome windows, Slack, and Notes open. You are in the first Chrome window. Press Command-Tab to jump to Slack. Press Command-Tab again to return to Chrome. Press Command-` to move through Chrome's windows.

To see the full list of open apps, hold Command and tap Tab. Keep holding Command, move through the list, and let go on the app you want.

The common mistake is pressing Command-Tab and expecting to see every window. You get apps. For a view of all open windows, use Mission Control, which Apple's shortcut list also covers. Give it a few days. Within a week, the split between apps and windows will feel natural.

## Closing windows, quitting apps and force quitting

On Windows, Alt+F4 closes the window you are in. On a Mac, closing a window usually does not quit the app. The app keeps running and stays in the Dock. Many switchers think they quit something, then find it still open and using memory.

Use these instead:

- Command-W closes the front window or tab in most apps.
- Command-Q quits the whole app, with every window.
- Option-Command-Esc opens Force Quit for an app that has stopped responding.

Say your browser freezes during a video call. Press Option-Command-Esc, select the browser in the list, and choose Force Quit. Then reopen it. Force quitting does not give an app a chance to save, so use it only when the app is truly frozen.

Ctrl+Shift+Esc on Windows opens Task Manager, which shows more than running apps. Force Quit only lists apps. Don't go looking for Task Manager on a Mac.

Command-Q is the one that catches people. It closes every window in the app. Save first, and read any prompt before you confirm.

## Moving files with Option-Command-V in Finder

Windows users cut with Ctrl+X and paste with Ctrl+V. On a Mac, you copy with Command-C, then move with Option-Command-V. Apple's shortcut list says Option-Command-V moves files on the clipboard from their original location to the current one.

1. In Finder, select the file and press Command-C.
2. Open the folder where the file should go.
3. Press Option-Command-V.

Say you want a PDF from Downloads in Documents. Select it, press Command-C, open Documents, and press Option-Command-V. The file moves. It does not stay behind in Downloads.

Don't assume Command-X works like Ctrl+X in Windows Explorer. Before you rely on it, open Finder's Edit menu and check which commands are active. If you copy a file and paste it into the new folder, you get a duplicate, and the original stays where it was. That is the habit to break first.

## Screenshots, Spotlight and locking the screen

For screenshots, Windows+Shift+S opens a region tool. On a Mac, Shift-Command-5 opens screenshot controls in macOS Mojave or later. Shift-Command-3 and Shift-Command-4 also take screenshots. If you want to grab a selected area, Shift-Command-4 is the closest match to the Windows habit.

For search, Command-Space opens Spotlight. Apple compares it to the Windows Start menu. Type an app name, a file name, or a search, then press Return.

For locking, Windows+L locks the screen. On a Mac, press Control-Command-Q. Command-L is a different job in most apps, so don't expect it to lock anything.

Here is a quick example. You step away from a shared desk. Press Control-Command-Q, and the screen locks. Come back, then enter your password to get back in.

## Right-click, Home, End and Delete

Right-click is Control-click. Apple's Windows keys page says holding Control and clicking performs a right-click. Do that with your mouse or trackpad.

Home and End map to Command-Left Arrow and Command-Right Arrow. Those move you to the start or end of a line. For the start and end of the whole document, use Fn-Left Arrow and Fn-Right Arrow.

Delete is the one that surprises people. The Mac Delete key erases backward, like Backspace on Windows. For forward delete, press Fn-Delete.

Try it in TextEdit. Put the cursor halfway through a long sentence. Press Command-Left Arrow to jump to the start of the line. Press Fn-Delete to remove the letter after the cursor. Then press Command-Right Arrow to jump to the end of the line and Delete to remove the letter before the cursor.

## Mistakes switchers make in the first week

- **Control-C in Terminal.** In Terminal, Control-C stops the running command. To copy text, use Command-C or the Edit menu.
- **Looking for Save under Ctrl.** Save is Command-S where it exists. Otherwise, check File in the menu bar.
- **Expecting Alt+F4 to quit.** Closing a window leaves the app running. Use Command-Q to quit.
- **Forgetting the Fn key.** Start and end of a document, and forward Delete, need Fn.
- **Assuming the same shortcut works everywhere.** Apple says shortcuts can differ by app. Check the menu bar when a shortcut does nothing.
- **Remapping too early.** Use the defaults for a few weeks before you change any keys. You will learn the real layout faster than a half-remapped one.

## A practice routine for the first weeks

Work through these in order. Don't try them all in one sitting.

1. Start with copy, paste, undo and redo in one text app. Keep at it until Command-Z feels automatic.
2. Move to window switching. Open two browser windows and one other app, then use Command-Tab and Command-`.
3. Practice closing with Command-W and quitting with Command-Q. In an app with nothing unsaved, quit once on purpose so you know where the command lives.
4. Try Option-Command-V in Finder with a throwaway file.
5. Last, learn screenshots, Spotlight and Control-Command-Q for locking.

Plan about one session per topic. Ten minutes a day for a week beats one long afternoon, because your fingers need repeats before the habit sticks.

## Should you remap Command and Control?

You can change modifier keys. Go to System Settings > Keyboard > Keyboard Shortcuts, then select Modifier Keys. Each key has a pop-up menu for its action. Apple's example is Caps Lock performing Control. Restore Defaults resets everything. Menu names can shift between macOS versions, so if the path looks different on your Mac, look for Modifier Keys in the Keyboard settings.

My advice: remap Caps Lock to Control if you miss a key where your pinky expects Ctrl. Then leave Command alone. Apple's menus print Command on most shortcuts. Swap Command and Control, and the menu labels and your fingers will disagree.
