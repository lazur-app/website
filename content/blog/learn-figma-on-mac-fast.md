To learn Figma on Mac, download the official desktop application from the Figma website and install it into your Applications folder. Once installed, sign in to your account to access your file browser and start your first project immediately.

## Why use the Figma desktop app on Mac

Many users start with a browser, but the desktop app offers a better experience. It acts like a native Mac application. You get access to local fonts installed on your system without needing any extra helper utilities. It also supports local development for plugins and widgets. This is vital if you plan to build custom design systems or automate parts of your workflow. The browser version is fine for quick edits, but the desktop app is where you should spend your time for serious work.

## System requirements for Figma

You need macOS 12 or later to run the Figma desktop app. If you are still running macOS 11 or older, you must use a supported web browser like Chrome or Safari. Always check your system settings before you download. You can find your version by clicking the Apple menu and selecting About This Mac. If your hardware supports it, update to the latest version of macOS to keep your software running smoothly.

## How to install Figma correctly

Go to the official Figma downloads page. Do not use third party sites. Download the installer file. Once it finishes, open the file and drag the Figma icon into your Applications folder. Delete the installer file to keep your Mac clean. Launch the application from your Applications folder. Sign in with your credentials. You are now ready to create your first file.

## Creating your first design file

After you sign in, you will see the file browser. This is your main dashboard. Click the New Design File button at the top right to start. Another way to do this is to type figma.new in your browser address bar. This shortcut creates a new file instantly. Once the file opens, you will see a blank canvas. This is where you will do your work. You can create frames, add text, and draw shapes using the tools in the top toolbar.

## Understanding the Figma interface

The interface is divided into three main parts. The left sidebar shows your layers and pages. The center is your canvas where you design. The right sidebar shows properties like color, size, and constraints for the selected object. Spend time clicking through these menus to see what each one does. Do not worry about breaking anything. You can always undo your actions with ⌘ Z.

## Managing your files and projects

Figma uses a cloud based system. You do not need to save files manually. Everything is saved automatically as you work. You can organize your work into projects and teams. The Starter plan is free for individuals. It allows for unlimited drafts. If you work with a team, note that there are limits on how many files you can share in team folders. Check the official pricing page to see the current limits before you start a big project.

## Common pitfalls for beginners

One common mistake is confusing the Figma app in the Mac App Store with the desktop design application. The App Store version is a mobile viewer for iPhone and iPad. It is not for designing. Always use the official website for the design app. Another mistake is forgetting to check for updates. While Figma updates automatically, you can force a check by using the Figma menu in the top menu bar. This ensures you have the latest features and bug fixes.

## Using local fonts in Figma

Figma allows you to use your local fonts. The desktop app handles this through a background process called Figma Agent. It has no interface, so you will not see it running. If you do not see your local fonts, ensure the desktop app is running and your fonts are installed in the Font Book app on your Mac. If they still do not appear, restart the Figma app. This usually fixes any connection issues between the app and your font library.

## Tips for a productive workflow

Learn keyboard shortcuts early. They make a huge difference in your speed. Use the shortcut panel to see all available commands. You can open this panel by pressing ⌃ ⇧ ?. Focus on learning the shortcuts for the tools you use most often, like the Frame tool or the Rectangle tool. Organize your layers with names to keep your files clean. This makes it easier to find things later when your projects grow in complexity. Use auto layout to make your designs responsive. If you need help with this, check out our guide on how to [add auto layout in Figma](/how-to/add-auto-layout-in-figma).

## When to use the browser instead

Sometimes the desktop app might have issues. If you experience performance problems, try switching to a browser like Chrome. It is a good backup if you are on a tight deadline and the desktop app is not behaving. You can also use the browser to quickly preview how your designs look to others. It is a good practice to keep both installed, but use the desktop app as your primary tool for daily work.

## Staying organized as you grow

As you learn, you will create many files. Use the search bar in the file browser to find them quickly. You can also star your most important files to keep them at the top of your list. If you are working on a large project, break it into smaller files or pages. This keeps the app running fast and makes it easier to manage your assets. Remember that Figma is a collaborative tool, so you can share your files with others easily. Learn how to [share a file with view access](/how-to/share-a-file-with-view-access-in-figma) so you can collaborate with your team.
