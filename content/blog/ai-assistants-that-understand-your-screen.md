An **AI assistant that understands your screen** uses the app or content already in front of you to produce a relevant result. That can mean drafting a reply from an email thread, rewriting a selected paragraph, or creating a coding instruction from the file open in your editor.

This is different from pasting a screenshot or a long block of context into a blank chat. The assistant is close to the work, so the request can be short: “reply warmly,” “make this clearer,” or “turn this into a Cursor task.”

## What screen-aware assistance looks like

The useful part is not visual recognition for its own sake. It is the reduction of context transfer:

1. You open the thread, document, or code file.
2. You give a short instruction in natural language.
3. The assistant uses the relevant context.
4. The result appears as a reply, rewrite, summary, or action.

Lazur uses this pattern with a global Mac hotkey and voice input. It can work with the front window and selected text, with optional screen access for requests that depend on visible context.

## Practical examples

| App context | Short request | Useful output |
| --- | --- | --- |
| Gmail thread | “Reply yes, Thursday works, keep it warm” | A ready-to-send response |
| Slack conversation | “Summarize this and give me the next action” | A concise summary and action list |
| Cursor file | “Add error handling and explain the change” | An agent-ready coding instruction |
| Notion document | “Turn this into a project brief” | A structured brief with headings |

## Privacy questions to ask

Before using any screen-aware assistant, check:

- Does it capture the screen continuously or only during a request?
- Is audio processed locally?
- Is screen content sent to a cloud model?
- Is context stored or used for training?
- Can you revoke Screen Recording permission?

Lazur's [privacy documentation](/privacy) explains its local speech-to-text and text-only cloud processing model. No assistant should ask you to trust vague privacy language.

## Screen-aware does not mean mind-reading

The assistant still needs a clear request. Screen context helps it understand who “they” or “this” refers to, but it does not replace judgment. Review generated messages, especially when a thread contains sensitive details or ambiguous requests.
