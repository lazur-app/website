Full Keyboard Access is a macOS setting that lets you reach every window, button, menu and list with the keyboard. Turn it on in Apple menu > System Settings > Accessibility > Motor > Keyboard, then use Tab and Shift-Tab to move between items and Space to select one.

## What Full Keyboard Access changes on your Mac

Your Mac already handles the basics from the keyboard. You can type in a text field, press Return to confirm a dialog, and switch apps with Command-Tab. The gaps show up everywhere else. By default, Tab moves between text boxes and lists only, so it skips most buttons, checkboxes and links. The A11Y Project describes that default in its guide to browser keyboard navigation.

Full Keyboard Access, which many people shorten to FKA, changes the rules. Once it is on, Tab can land on any control in the window you are using. Arrow keys move within a group, such as a sidebar or a file list. Space selects the item that has focus. Apple's help pages describe these same roles.

FKA does not make every app behave the same way. macOS sends focus to a control, but the app decides what happens next. I did not test individual apps for this guide. Run a short check in the apps you use every day. Finder, System Settings and your browser are a good place to start.

## How to turn on Full Keyboard Access step by step

Here is the full path. The menu names come from Apple's current help pages.

1. Click the Apple menu, then choose System Settings.
2. Click Accessibility in the sidebar. Scroll down if you don't see it.
3. Click Motor, then click Keyboard.
4. Turn on Full Keyboard Access.

Press Tab a few times once it is on. Watch the focus outline move from item to item. If nothing moves, click a window first, then try again. Tab needs an active window to work inside.

There is a faster switch. Apple says Option-Command-F5 turns Full Keyboard Access, Sticky Keys, Slow Keys or the Accessibility Keyboard on or off. On a Mac with Touch ID, press Touch ID three times quickly instead. If the shortcut switches something you did not expect, open the Info button next to Full Keyboard Access in the same settings. It shows the command shortcuts, and you can customize or restore them there.

Naming can confuse you. Guides from 2017 to 2019 describe a Keyboard > Shortcuts checkbox and an All controls radio button. Apple's current pages use Accessibility > Motor > Keyboard. Six Colors, writing in October 2025, calls the Control-F7 toggle “Keyboard navigation.” If your labels differ, look for the same idea under the name your version uses.

## The keys to learn first

Apple lists a set of keys for FKA. Most people use only a handful each day. The table groups them by what they do.

| Keys | What it does |
|---|---|
| Tab / Shift-Tab | Move to the next or previous item |
| Control-Tab / Control-Shift-Tab | Reach items the arrow keys cannot |
| Arrow keys | Move within a group, such as a sidebar or file list |
| Space | Select the item in focus |
| Tab-W | Open the Window Chooser for the current app |
| Tab-A | Open the Application Chooser |
| Control-F5 | Move focus to the window toolbar |
| Control-F6 | Move focus to the floating window |
| Command-` | Cycle through windows of the app you are using |
| Tab-H | Open Commands Help |
| Control-Option-Command-P | Turn Pass-Through Mode on or off |

Start with five keys: Tab, Shift-Tab, Space, Tab-W and Command-`. Those cover most daily work. Add the others once the first five feel normal.

Apple writes some of these with hyphens, such as Tab-W. Press the keys in the order Apple's page shows. Apple also says some focus shortcuts must be enabled in System Settings > Keyboard > Keyboard Shortcuts before they work. If Control-F5 or Control-F6 does nothing, check that pane first.

## Move between windows without a mouse

Most window problems come down to picking the right scope. Here is a common case. You have a Pages report open with two documents, a Safari tab with research, and a Mail draft. You want the Safari window.

Use the shortcut that matches the scope you need.

- Command-` cycles through the windows of the app you are in. If Pages has two documents open, this moves you between them. It does not reach Safari.
- Tab-W opens the Window Chooser, which lists the current app's windows. Use the arrow keys to move through the list, and Space to pick one. Apple's pattern for lists is arrow keys and Space, so expect that here.
- Tab-A opens the Application Chooser, which switches between open apps. Command-Tab does a similar job for most people, so use whichever feels faster.

Tab-W only lists the current app. If the window you want belongs to another app, press Tab-A first to switch apps, then press Tab-W. That two-step habit saves more time than any single shortcut.

Control-F5 moves focus to the window toolbar. Use it when you want a toolbar button without tabbing through the whole window. Control-F6 moves focus to a floating window, such as a tool panel. Both need the focus shortcuts turned on, as noted above.

## Reach the menu bar, Dock and Control Center

The menu bar is the part people miss most. Apple lists these keys for the bars and panels that sit outside a window:

- Fn-Control-F2 for the menu bar
- Fn-A for the Dock
- Fn-C for Control Center
- Fn-N for Notification Center
- Tab-F to search items
- Tab-H for Commands Help

Some keyboards label the Fn key as Globe. Use the key with that label if your keyboard shows it.

Here is a worked example. You want to check your Wi-Fi status without touching the trackpad. Press Fn-C to reach Control Center. Then press Tab until the Wi-Fi control has focus, and press Space to select it. If you forget a key, press Tab-H to open Commands Help and look it up there.

## Stop Tab from skipping buttons

This is the setting that causes the most confusion. Control-F7, or Fn-Control-F7 on a laptop, changes what Tab reaches. One mode sends Tab to every on-screen control. The other sends Tab only to text boxes and lists. Apple documents this change on its keyboard shortcuts page.

To test it, open Finder, press Control-F7, and then press Tab several times. If focus moves onto buttons and toolbar items, the all-controls mode is on. Press Control-F7 again to go back to the default. Check the result before you decide which mode you want.

Advanced users can set the same mode from Terminal. The A11Y Project documents this command: defaults write NSGlobalDomain AppleKeyboardUIMode -int 3. The guide says it writes the same all-controls setting. Restart any open browser after you change it. Paste it only if you are comfortable in Terminal.

## Browsers stop on links

Browsers add their own layer on top of macOS. You may find that Tab reaches buttons in Finder but skips links on a web page. The A11Y Project's browser guide dates from 2017 and was updated in 2019. Check the menu names in your browser version before you follow it. I did not re-check current browser menus for this article.

| Browser | Setting named in the guide | Note from the guide |
|---|---|---|
| Safari | Advanced: Press Tab to highlight each item on a webpage | The guide says Preferences > Advanced |
| Chrome | Appearance: Pressing Tab on a webpage highlights links, as well as form fields | Restart the browser after you change it |
| Firefox | Set accessibility.tabfocus to 7 in about:config | May still skip links, even with all controls on |

Here is how to test Safari. Turn on the Advanced setting, then press Tab on a news page. Links should take focus one at a time. If they don't, check Control-F7 and restart Safari. Then test again.

## What Full Keyboard Access cannot fix

Some controls ignore focus. An app may draw its own buttons, or a web page may build custom widgets that look like buttons but skip the standard focus path. You will see this in some web apps and in a few Mac apps. When it happens, the gap sits in the app, not in your settings.

The web has this problem at scale. WebAIM's Million 2026 check looked at one million home pages. It found detected WCAG 2 failures on 95.9% of them, up from 94.8% in 2025. The average page had 56.1 detected errors, up 10.1% from 51. That study measures general accessibility, not keyboard focus. Read it as context for why these gaps keep showing up.

When an app blocks focus, use the menu bar with Fn-Control-F2 as a fallback. Press Tab-H to look up the command you need. You can also ask a voice assistant where the control is, as covered near the end of this guide.

## Pause Full Keyboard Access when you need the mouse

Pass-Through Mode is the escape hatch. Press Control-Option-Command-P to turn it on or off. Apple describes it as a way to pause Full Keyboard Access temporarily, for example in games.

The common mistake is assuming something is broken. Clicks or keys may behave oddly, and you start looking for a bug in the app. Check Pass-Through Mode and Control-F7 first. That check takes seconds and avoids a long search.

## Who this helps and what the numbers show

The CDC says more than 1 in 4 U.S. adults have some type of disability. It reports that 12.2% have a mobility disability, 13.9% a cognitive difficulty and 5.5% a vision difficulty. These categories overlap, so the figures do not add up to one total. The infographic cites survey data updated in July 2024 and does not give the survey year. Treat the numbers as recent context, not a snapshot of today.

For people who find a mouse or trackpad hard to use, a keyboard path is often the main way into a Mac. The same path helps anyone who wants fewer hand movements during long sessions. That is a practical benefit, not a measured one.

The numbers have limits. I found no study on how many Mac users turn on FKA. I also found no figure for how much time it saves. Be wary of any time-saved claim that does not say how it was measured.

## Common mistakes to avoid

- Expecting every app to respond the same way. Test each app before you rely on it.
- Leaving Pass-Through Mode on. If keys stop responding, press Control-Option-Command-P and check.
- Pressing Control-F5 or Control-F6 and seeing nothing. Enable the focus shortcuts in System Settings > Keyboard > Keyboard Shortcuts.
- Mixing up Command-` and Tab-W. Command-` cycles windows directly. Tab-W opens a list you move through with arrow keys.
- Trusting a shortcut description without testing it. Six Colors flagged that Apple's description of the Power-key combination says it shuts down the Mac, when it restarts it. Test shortcuts on your own machine before you rely on them.

## A one-week practice plan

Spend a few minutes each day. Each day adds one part.

- Day 1: Turn on Full Keyboard Access. Press Tab through Finder and System Settings.
- Day 2: Use Tab-W and Command-` for every window change in your main app.
- Day 3: Practice Tab-A and Command-Tab side by side. Keep the one that feels faster.
- Day 4: Reach the menu bar with Fn-Control-F2, and the Dock with Fn-A.
- Day 5: Set Control-F7 the way you like it. Test Tab in your browser.
- Day 6: Open the Info button in Full Keyboard Access settings, and read the command shortcuts list.
- Day 7: Do one real task without the mouse. Write a reply in Mail or a note in Notes.

Some apps have their own shortcut lists on top of FKA. Numbers, for example, has its own key set, covered in [how to use keyboard shortcuts in Numbers on Mac](/how-to/use-keyboard-shortcuts-in-numbers). If Gmail runs in your browser, its shortcuts are a separate setting. The steps are in [how to turn on keyboard shortcuts in Gmail on Mac](/how-to/turn-on-keyboard-shortcuts-in-gmail). Learn them as separate sets, not as one list.
