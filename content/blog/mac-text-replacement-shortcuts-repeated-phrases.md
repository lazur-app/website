Mac text replacement shortcuts are Apple's built-in way to type a short code and have it expand into a full phrase. You set them up once in System Settings, and they sync to other Macs signed in with the same Apple Account when iCloud Drive is on. The catch is that they do not work in every app, and some popular apps ignore them completely.

This guide covers the setup path, the menu options inside apps, the limits you will actually hit, and what to do when an expansion fails. If you only want one shortcut working today, read the setup section and stop there.

## What Mac text replacement does

Text replacement is not a keyboard shortcut. You do not hold ⌘ or ⌥ to trigger it. You type a short piece of text, and the Mac swaps it for a longer phrase you saved.

Every entry has two parts. The first is the text you type. The second is what it becomes. Apple's help calls these "the text to replace" and "its replacement." The idea is simple.

It works a bit like autocorrect, except you write the pairs yourself. That is the whole feature. Everything else in this guide is about where it runs, where it fails, and how to keep the list usable.

A fresh macOS install comes with a few entries already in the list. TheSweetBits reports three defaults: btw, maam, and omw. If you see them, the feature is there. You can delete them if you never use them.

## How to set up a text replacement on Mac

Apple's steps are short. Follow them in this order.

1. Choose Apple menu > System Settings.
2. Click Keyboard in the sidebar. On a small window, scroll down until you see it.
3. Click Text Replacements.
4. Click Add.
5. Type the short text in the first field, then the full phrase in the second field.
6. Click Add to save the entry, then click Done.

Pick the trigger with care. A common word such as "ok" or "the" will expand every time you type it, and that gets annoying fast. Use a string you never type by accident. A prefix such as "x" works well, so "xaddr" is safer than "addr".

Here is a worked example. You ship orders from a home office and type your return address many times a week. Create an entry with the trigger "xaddr" and paste the full address into the second field. Click Add, then Done. Open Notes, type "xaddr," and check that the address appears.

Some sources say the feature handles only single-line text. TypeFire, a competing app vendor, says so directly. An Apple Community user reported that a replacement can hold about 2,000 characters, including line breaks. Those two claims conflict. Test a multi-line address in the app you use before you depend on it.

## How to add a replacement from inside an app

You do not always need System Settings. From most apps that support the feature, open the Edit menu and follow Edit > Substitutions > Show Substitutions. Then choose Text Settings to reach the same list.

This route is useful when you are already in a document and want to see the feature's controls next to your text. It is the same list, so any change you make here shows up in System Settings too.

Two more Edit menu paths matter in daily use.

To turn replacements on or off for one app, choose Edit > Substitutions > Text Replacement. A checkmark shows whether it is on. If your expansions do nothing in an app, check this first.

To change text that you already typed, choose Edit > Substitutions > Show Substitutions. Select Text Replacement, then pick Replace in Selection or Replace All. This is handy when you added an entry after writing the draft.

## Which apps support text replacement

Apple's own help says text replacements, smart quotes and dashes, and smart links "aren't available in all apps." That line is the one to remember. Support depends on the app, and the sources do not agree on every app.

Here is what the sources say, with each claim labeled by who made it.

| App or type | What the sources say | What to do |
| --- | --- | --- |
| Notes, Mail, Messages, Safari | TypeFire, a competing vendor, says the feature works in Apple's own apps | Test once with a trigger you know |
| Microsoft Word for Mac | TheSweetBits says Word does not support it unless the developer enables it. LazyBoard, a vendor, says Word uses its own AutoCorrect list | Use Word's AutoCorrect entries for the same phrases |
| Chrome | TypeFire says it works in some fields only | Test each web field you use |
| Slack desktop app | TypeFire says it is not supported. LazyBoard says results in Slack and Discord are inconsistent | Test before you rely on it |
| Google Docs and rich web editors | LazyBoard says these editors handle typing themselves | Expect no expansion, or check the editor's own settings |
| VS Code | TypeFire names it as an app that does not support the feature | Use the editor's snippet tools |

The pattern is clear enough. Apple's own apps are the safest bet. Editors that run their own typing engine are the usual trouble spot, including Google Docs, Word, and many web forms.

Do not trust a single test. Type your trigger in each app you use every day, then see whether it expands. Five minutes of testing saves you from a broken shortcut during a deadline.

## Where text replacement breaks and how to fix it

Most failures fall into a few groups. Work through them in order.

The first group is settings. The per-app checkbox at Edit > Substitutions > Text Replacement might be off. TheSweetBits suggests a short sequence: restart the Mac, check Edit > Substitutions, enable Text Replacement, then remove the entry and add it again.

The second group is the app itself. If an entry works in Notes but not in one other app, that app probably ignores the feature. LazyBoard recommends checking Edit > Substitutions in the failing app, re-adding the replacement, restarting, and updating macOS. It also suggests recreating your five most-used replacements first, so you know which ones matter.

The third group is language input. Apple says that with Chinese or Japanese input sources, replacements are stored in the user dictionary. If your expansions behave oddly after you switch input sources, check that dictionary before you blame the feature.

The fourth group is sync. TypeFire says iCloud sync for the built-in feature is unreliable, and that entries may disappear, duplicate, or fail to sync. Apple says the feature syncs when each device has iCloud Drive and the same Apple Account. If you see duplicates, delete the extras on one Mac, then check the other devices. Keep a backup file, covered below.

Edge cases catch people off guard. A trigger that is also a real word can fire in the middle of a sentence you did not mean to change. A phrase with a trailing space may not behave the way you expect. Test the exact text you want, not a rough version of it.

## Limits: search, folders, and how many entries is too many

The built-in list has no folders and no search. You scroll. An Apple Community thread from December 13, 2025, on macOS 26.1, asked how to search the Text Replacement list in System Settings > Keyboard. The answer was that there is no search box. The thread was closed without an accepted fix.

Apple does not publish a cap on the number of entries. Its help page gives no entry caps or format limits. Some numbers come from users and vendors, not Apple.

One user in the Apple Community thread reported more than a hundred entries. TypeFire says the built-in list suits five to ten simple, single-line replacements, and becomes hard to organize beyond about 20 entries. TypeFire is a vendor with its own app to sell, so treat that as a rule of thumb.

The practical rule is simple. Keep the list short enough that you can find any entry by eye. Start with your five most-used phrases, the same advice LazyBoard gives. Add more only after those work in every app you use.

Older Macs have a different menu. TheSweetBits says the main method works on macOS Ventura and later. On Monterey, the path is System Preferences > Keyboard > Text. The Apple guide I checked describes the newer System Settings path, so use that on current systems.

## How to back up and share your text replacements

Export a backup before you change anything big. Apple's guide shows a clean way to do it.

Open System Settings > Keyboard > Text Replacements. Select the entries you want, or choose Edit > Select All. Then drag the selection to your desktop. The Mac creates a file named "property list.plist."

To import, drag the file back into the Text Replacements window, then click Done.

Keep that file in a folder you back up. If sync duplicates or drops entries, you have a clean copy to restore from. The file also helps when you set up a second Mac and want the same list without retyping every phrase.

## Mistakes people make with Mac text replacement shortcuts

These mistakes come up again and again.

Choosing triggers that are real words. "ok," "thx," and "the" cause constant false expansions. Use a prefix that you never type on purpose.

Testing in one app and assuming it works everywhere. Notes is the easy case. Google Docs, Word, and many web forms are the hard cases. Test in the app you actually use for the work.

Building a long list too early. A big list with no search is slow to manage. Start small and add entries only when you need them.

Forgetting the per-app checkbox. A replacement can be correct and still do nothing because Text Replacement is off in that app.

Mixing up text replacement with smart quotes and dashes. Apple lists these as separate features, and they also vary by app. If a dash or quote looks wrong, check that setting on its own.

Trusting sync without checking. TypeFire reports sync problems. Check your list on each Mac after you add something important, and keep the export file.

## Starter shortcuts that pay off

The best first entries are the phrases you type every week. They save the most time and carry the least risk, because nobody types them by accident.

| Trigger (example) | Expands to | Where it helps |
| --- | --- | --- |
| xaddr | Your full return address | Shipping forms, invoices, checkout pages |
| xsig | Your email sign-off | Mail and Notes replies |
| xlink | Your booking or calendar link | Messages and email follow-ups |
| xdraft | A standard opening for status updates | Work chats and reports |

These triggers are examples I made up, not defaults. Pick triggers that match your own work. Then check how many keystrokes you actually save with the [typing speed test](/tools/typing-speed-test) before you decide the list is worth keeping.

## Built-in text replacement or a different tool?

Use the built-in feature when your phrases are short and your apps are mostly Apple's own. It is free, it lives in System Settings, and it needs no extra app.

Look elsewhere when you need long, formatted text, folders, search, or support in apps that ignore the built-in feature. Third-party expansion apps exist. TypeFire is one, and it makes claims about where the built-in feature stops. Check their pricing page for current costs, because I could not verify prices from the sources here.

Text replacement and find-and-replace also solve different problems. Text replacement changes what you type next. Find and replace changes text that is already on the page. If you need to fix a document you wrote earlier, see [how to find and replace in Numbers on Mac](/how-to/find-and-replace-text-in-numbers).

## What to do next

Start with one entry today. Pick a phrase you type every week, give it a prefix trigger, and save it in System Settings.

Then test it in the three apps you use most. If one fails, check Edit > Substitutions in that app before you change anything else.

Finally, export the list to a property list file and keep it somewhere safe. That file is the fastest way back if sync goes wrong.
