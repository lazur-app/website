Open the Shortcuts app, double-click the shortcut, click the info button, then choose Add Keyboard Shortcut and press the keys you want. After that, the shortcut runs from any app on your Mac, and you do not need to open Shortcuts first.

You have more ways than a keyboard shortcut. You can also run a shortcut from the Share menu, as a Finder Quick Action, from the Services menu, or from Control Center. Each route needs a different setting, and each has its own limits. This guide walks through all of them, then covers the mistakes that make a shortcut disappear.

The steps follow Apple's Shortcuts guide for macOS 27 Golden Gate. Apple released macOS 27 to the public on September 14, 2026. macOS 27.2 shipped on October 26, and macOS 27.3 entered public beta on November 5. Menu labels can move between point releases. If a name below does not match your screen, look for the closest match in Apple's guide for your version.

## What you need before you start

You need a shortcut that already exists. Open the Shortcuts app and check the sidebar. If your list is empty, build something small first. A shortcut that opens a new note from a template is a good test, because you see the result on the first try.

macOS 27 can also build shortcuts from a plain description. Apple Intelligence handles that part. MacRumors says the feature is in beta and "not always perfect." Read through what it builds before you assign a key to it. A shortcut you do not trust is a shortcut you stop using.

Pick the route by the job, not by habit. A keyboard shortcut works everywhere, but it does not know what you have selected. The Share menu and Finder Quick Actions work on selected content. The Dock and the menu bar work on nothing at all. The table near the end lays this out side by side.

If you also want to change which keys macOS and your apps respond to, read [how to customize Mac keyboard shortcuts without breaking your apps](/blog/customize-mac-keyboard-shortcuts) before you start. If you only need a short phrase typed out, a text replacement is a different tool, and [Mac text replacement shortcuts for repeated phrases](/blog/mac-text-replacement-shortcuts-repeated-phrases) covers that job.

## How to run a Mac shortcut with a keyboard shortcut

This is the route most people want. It works in any app. Once it is set up, you press the keys and the shortcut starts.

1. Open the Shortcuts app.
2. Double-click the shortcut you want to run.
3. Click the info button.
4. Click Add Keyboard Shortcut.
5. Press the key combination you want. The shortcut is now live in every app.

Choose a combination with Control, Option, or Command plus a letter or number. ⌃⌥⌘ M is a good pattern. Plain letters and single keys clash with typing in almost every app. Apple's guide says some combinations are reserved for macOS and cannot be overridden. Command Space, which opens Spotlight, is one example of a combination macOS keeps for itself. If you press a reserved combination, the shortcut does not take it.

Here is a worked example. You write meeting notes every morning. You build a shortcut called Meeting Notes Template that opens a new note with your headings already in place. You assign it ⌃⌥⌘ M. Now you can press those three keys in Safari, Mail, or Notes, and the template appears. You never open Shortcuts.

To remove a keyboard shortcut, open the same info panel, click the Run with field, and press Delete. Then assign a new combination if you want one. Removing the old key first keeps your list of combinations clean, and it makes it easier to see which key does what six months from now.

## How to run a shortcut from the Share menu

The Share menu is useful when you already selected something. It sends your selection to a shortcut. Apple calls this the Share Sheet. To turn it on, double-click the shortcut, click the info button, click Details, and select Show in Share Sheet.

The first time, you must also grant the Shortcuts sharing extension permission in System Settings. Apple's guide describes this as a one-time step. If you skip it, the shortcut will not appear when you share.

To run it, follow these steps:

1. Select text, a link, or a file in the app.
2. Click Share.
3. Click Shortcuts.
4. Select your shortcut.
5. Click Done.

Example: in Safari, select a paragraph from an article. Share it to a shortcut that saves the text into a note. The shortcut works on the content you chose, so you skip the copy and paste step entirely.

The Share menu has a limit that catches people fast. A shortcut may not appear in the Share menu if the app has no content that the shortcut accepts. So a shortcut built for image files will not show up when you share a line of plain text. If a shortcut is missing, open it in the editor and look at what it expects as input. Then test it with that kind of content.

## How to run a Mac shortcut as a Finder Quick Action

Quick Actions put your shortcut in the right-click menu for files in Finder. You turn them on in two places.

First, double-click the shortcut, click the info button, and turn on Use as Quick Action. Second, open Apple menu > System Settings > Privacy & Security > Extensions > Finder, and enable the shortcut there. Apple's steps need both. Skip the second one, and the Quick Action will not show up in Finder.

To run it, Control-click a file or folder in Finder. Choose Quick Actions, then your shortcut name.

Example: say you export screenshots into a folder called Client Work, and you need them sorted by date. Build a shortcut that moves the selected files into a dated subfolder. Then select the files in Finder, Control-click them, and run the shortcut from Quick Actions. You never open the Shortcuts app for the daily run.

Quick Actions suit file jobs. They do not suit text you select in a browser or a chat app. For that, use the Share menu.

## Services menu, Control Center, Dock, and Spotlight

The Services menu gives you a second Finder route. Double-click the shortcut, click the info button, and select Services Menu. Run it from Finder > Services. If the entry is missing, the shortcut may be disabled, so check that first.

Some third-party guides describe a binding path: System Settings > Keyboard > Keyboard Shortcuts > Services, where you assign a key to a Services entry. I could not confirm that path on Apple's pages. Check it on your own Mac before you rely on it.

Control Center is the menu bar route. Click the Control Center icon, choose Edit Controls, click Shortcuts, then pick Open App, Run Shortcut, or Show Menu Bar collection. Forum posts disagree about where this option lives. One post about Tahoe says the add to menu bar option was removed. A MacScripter thread says it sits in Control Center's Shortcuts section. Apple's guide supports the Control Center route, so start there.

Here is the limit that matters most. Shortcuts run from the Dock or the menu bar do not receive content from other apps as input. If your shortcut needs selected text or files, use the Share menu or a Quick Action instead. Dock and menu bar shortcuts suit jobs that need no input, such as opening a set of apps or starting a routine.

Apple's intro also lists the Actions pop-up menu, the Touch Bar on MacBook Pro, and the command line as ways to run a shortcut. The Touch Bar and the Actions pop-up menu are handy if you already work with those controls, but the keyboard shortcut is the one you can rely on across apps.

Spotlight is the last route. MacRumors reports that macOS 27 indexes shortcut actions and app intents, so they run faster from Spotlight. Coverage of Tahoe describes Quick Keys, which bind a key combination to a specific shortcut. I found no 2026 source that confirms how Quick Keys behaves now. Test it on your Mac before you depend on it.

## Which route should you pick

| Method | Turn it on | Run it | Best for |
|---|---|---|---|
| Keyboard shortcut | Info, then Add Keyboard Shortcut | Press your keys in any app | Shortcuts you run many times a day |
| Share menu | Info, Details, Show in Share Sheet | Select content, Share, Shortcuts | Acting on text, links, or files you chose |
| Finder Quick Action | Info, Use as Quick Action, then Extensions > Finder | Control-click a file, Quick Actions | Working on files in Finder |
| Services menu | Info, Services Menu | Finder > Services | Finder jobs when a key is already taken |
| Control Center | Edit Controls, then Shortcuts | Click the Control Center icon | Shortcuts that need no input |

My rule is simple. Daily shortcuts get a keyboard combination. Anything that acts on selected text gets the Share menu. Anything that acts on files gets a Quick Action. Everything else can wait in Control Center.

## Test each route once before you trust it

Setting up four routes for one shortcut sounds like too much. It is not. Each test takes a few seconds once the setting is on. Run through this checklist for every shortcut you care about.

1. Press the keyboard shortcut in Safari, then in Notes, then in Finder. If it works in all three, you know the combination is free.
2. Select some text in Safari, click Share, and check that the shortcut appears under Shortcuts.
3. Select a file in Finder, Control-click it, and check Quick Actions.
4. Open Finder > Services and check the entry if you turned it on.
5. Click the Control Center icon and check the Shortcuts control if you added it.

Expect some routes to fail for the shortcut you built. A shortcut designed for text will often fail on a file, and that is fine. Pick the route that matches the input, and move on. The point of the test is to find the right route, not to make every route work.

## Mistakes and fixes when a shortcut won't run

| What you see | Likely cause | Fix |
|---|---|---|
| Keyboard shortcut does nothing | macOS reserves the combination, or another app uses it | Pick another combination, and remove the old one with Run with and Delete |
| Share menu does not list the shortcut | Permission not granted, or the app has no content the shortcut accepts | Grant the sharing extension permission in System Settings, then test with the right content |
| Quick Action missing from Finder | The Extensions > Finder toggle is off | Enable the shortcut in Privacy & Security > Extensions > Finder |
| Services entry missing | The shortcut is disabled | Enable the shortcut, then reopen the Services menu in Finder |
| Dock or menu bar run gets no text | Those runs get no content from other apps | Use the Share menu or a Quick Action instead |

The hardest problem to spot is a key that another app already uses. Nothing warns you when that happens. If your combination works in Notes but not in one specific app, the app is the likely cause. Move the shortcut to a different combination and test again.

Many people also expect the Dock icon to act on what they selected. It will not. Treat the Dock and the menu bar as launchers for shortcuts that start from nothing. Use the Share menu or a Quick Action when you need the selection.

## Run a shortcut from Terminal with shortcuts run

Apple's command-line guide gives you a direct route for scripts. The syntax is shortcuts run "Name", with the shortcut name in quotes. Add -i or --input-path to pass an input file, and -o or --output-path to save the output. The command exits with 0 on success and 1 on error.

Here is the command for the meeting template from earlier:

shortcuts run "Meeting Notes Template"

Shortcuts that ask for input or show alerts pause the command until someone responds. So a script that calls one unattended will stall. Choose shortcuts that need no input before you wire them into a script, and keep the interactive ones for the keyboard.
