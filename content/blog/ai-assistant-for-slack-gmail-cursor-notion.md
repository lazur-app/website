An **AI assistant for Slack, Gmail, Cursor, and Notion** should follow your work across apps instead of making you rebuild context in four separate chats. Lazur gives you one system-wide voice interface on Mac for replies, rewrites, prompts, summaries, and next actions.

The app-specific task changes, but the workflow stays simple: look at the work, say what you need, review the result, and keep moving.

## Slack: turn conversations into action

Slack work is often a mixture of decisions, questions, and unfinished threads. A useful assistant can:

- Draft a reply in the tone of the thread
- Summarize a long conversation
- Turn a decision into a task list
- Write a concise standup update

Example: “Summarize this thread and write the update for the project channel.”

## Gmail: write the reply, not the instruction

Email assistants are most useful when they understand the relationship between the previous message and your intended response. Try requests such as:

- “Reply that Thursday works and ask for the deck.”
- “Make this shorter and more direct.”
- “Follow up politely on the unanswered question.”

Lazur's Gmail workflow is designed around the thread already open, not a blank prompt. See the [Gmail use case](/use-cases/gmail).

## Cursor: describe the change

Developers rarely want a transcript of a spoken coding request. They want an instruction an agent can execute. A context-aware assistant can turn “refactor this, add error handling, and keep the API unchanged” into a precise coding prompt using the file or selection in front of you.

See [Lazur for Cursor](/use-cases/cursor) and the guide to an [AI assistant for developers](/blog/ai-assistant-for-developers-and-coding-tasks).

## Notion: organize the thought

Notion work often begins as scattered research, meeting notes, or a rough project idea. Ask the assistant to:

- Turn notes into a brief
- Extract decisions and owners
- Convert a page into an outline
- Rewrite a section for a specific audience

## One workflow, different outputs

| App | Best assistant job |
| --- | --- |
| Slack | Reply, summarize, decide |
| Gmail | Draft, follow up, change tone |
| Cursor | Explain, refactor, create agent prompts |
| Notion | Structure, outline, synthesize |

The value is not that every app behaves the same. The value is that you do not need to learn a new assistant workflow for each one.
